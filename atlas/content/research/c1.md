# C1: Nowcasting the public share between Z.1 releases

> The evaluation design is Eleonora's (her Q-C1 decisions of 2026-11-04, recorded in PLAN.md). The implementation details Claude added are marked in `EVALUATION.md`.

**PLAN task C1. Status: development-sample evaluation done; holdout run once on 2026-11-05 (see the joint holdout write-up).** The acceptance criteria are a point-in-time panel, in which each input is read at the value public at the nowcast instant, and a release-lag table per input. The panel is `pit.panel(t)`. The table is [`release_lags.csv`](https://github.com/eleonorabjornberg/household-debt-risk/blob/main/research/c1_nowcast/release_lags.csv). The Z.1 release calendar is [`z1_calendar.csv`](https://github.com/eleonorabjornberg/household-debt-risk/blob/main/research/c1_nowcast/z1_calendar.csv). Candidate inputs are listed in [`inputs.yaml`](https://github.com/eleonorabjornberg/household-debt-risk/blob/main/research/c1_nowcast/inputs.yaml), and the sources with their hashes in [`sources.md`](https://github.com/eleonorabjornberg/household-debt-risk/blob/main/research/c1_nowcast/sources.md).

## Results: development sample only (targets to 2023Q2; the holdout result is in the joint holdout write-up)

> The scores below follow [`EVALUATION.md`](https://github.com/eleonorabjornberg/household-debt-risk/blob/main/research/c1_nowcast/EVALUATION.md), which was committed before any score existed (7ae4afb). Changes made after the first scores, in response to the quant-reviewer and skeptic, are listed there under "Deviations"; the first scores are in commit 58a93d8. The holdout (2023Q3–2026Q2, as frozen in C2) is untouched. So under C2's wording rule, nothing here can yet be called "beats".

**Real time (RT)** means: the Z.1 base comes from the Fed's release archive (all 41 releases from 2016-09-16), the indicators from ALFRED as of each instant, and the target is the first release. Monthly instants run from October 2016; targets run 2016Q3–2023Q2. Each target is scored once per instant index k (k = 1 is the first monthly instant after a Z.1 release). A rare fourth instant before the next release is kept but not scored. RMSE relative to no-change (below 1 is better):

| 3 | 22 | 0.76 | 0.10 / 0.51 | 10 | 0.54 | 0.86 | 0.02 / 0.16 | 0.97 | 0.86 |

- **The accounting bridge** has an RMSE of 0.29 pp, against 0.39 pp for no-change, pooled over k: about a quarter lower. After the Holm correction the difference is not significant at any k. Under C2's wording it is so far "comparable to the benchmark". Errors at consecutive quarters are autocorrelated within each k, so the lag-0 p-values are, if anything, too small. A post-hoc lag-1 version is in `tests_dev.csv`.
**What this does not show.**
- It does not show accuracy on unseen data. The holdout was run once on 2026-11-05; its result is in the joint holdout write-up, not here.
- The samples are small (about 20–28 targets per k in RT). All p-values are descriptive.
- C2's placebo and outcome leakage checks are not implemented for C1 (see Deviations).
- The bias finding suggests adding the agency monthly summaries (indicator set 2c), but that would be a new, separately pre-registered run and never a change to this one.
