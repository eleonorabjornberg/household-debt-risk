# Getting started with Tableau Public

This guide gets the **Ratchet** chart from this repo onto Tableau Public and then into the website (https://household-debt-risk-web.vercel.app). It assumes you have never used Tableau. Tableau Public is free. The data is public, so publishing it publicly is fine.

What you have in this folder:

| File | What it is |
|---|---|
| `WhoHoldsTheDebt.twbx` | **Open this one.** A packaged workbook: the charts plus a copy of the data, all in one file. |
| `WhoHoldsTheDebt.twb` | The same workbook without the data inside (used by the build script; ignore it). |
| `data/*.csv` | The data as plain spreadsheets, one file per dashboard. Written by the pipeline (`hhdebt export-tableau`). |
| `build_workbook.py` | Regenerates both workbook files from the CSVs: `python3 -I tableau/build_workbook.py`. |

> **Heads-up.** The workbook file was generated by a script. No copy of Tableau was available to test it, so you are the first person to open it. If anything looks off, see [If the file doesn't open or looks wrong](#5-if-the-file-doesnt-open-or-looks-wrong). There is also a [10-step manual rebuild](#6-plan-b-rebuild-the-ratchet-by-hand-about-10-minutes) that doesn't depend on the file at all.

---

## 1. Install Tableau Public and create a profile

1. Go to https://public.tableau.com and click **Sign Up** (top right). Create a free account. Your **profile name** is the last part of your profile URL (`https://public.tableau.com/app/profile/<profile-name>`). Write it down, because the website needs it in step 8.
2. Download the free desktop app from https://www.tableau.com/products/public/download. It's called **Tableau Public** (sometimes "Tableau Public Desktop").
3. Install it and open it. Sign in with the same account when it asks.

## 2. Open the workbook

1. In Tableau Public choose **File → Open…** and pick `tableau/WhoHoldsTheDebt.twbx`. Double-clicking the file also works.
2. Tableau may say the file was made with an older version and will be upgraded. Click **OK**. This is expected.
3. You should land on the **Ratchet** dashboard. It shows a title, a coloured stacked-area chart filling from 0% to 100%, a colour legend and a single line below it.

## 3. A quick tour of the screen

1. **Sheet tabs (bottom).** Each tab is a *sheet*. A **worksheet** (small bar-chart icon) holds one chart. A **dashboard** (grid icon) arranges several worksheets on one page. This workbook has two worksheets, **Ratchet – main** and **Public share**, and one dashboard, **Ratchet**. Tableau doesn't allow a worksheet and a dashboard to share a name, so only the dashboard is called "Ratchet". Click a worksheet tab to look inside it.
2. **Data pane (left).** Lists the fields (columns) of the data source `ratchet`. Blue fields are *discrete* (categories, like `Bucket label`). Green fields are *continuous* (numbers or a time axis, like `Share of total`).
3. **Columns and Rows shelves (top).** Whatever you drop on **Columns** becomes the horizontal axis and whatever you drop on **Rows** becomes the vertical axis. In *Ratchet – main*, Columns has `QUARTER(Date)` (green, so a continuous timeline) and Rows has `SUM(Share of total)`.
4. **Marks card (left, under Filters).** It controls how the data is drawn. The dropdown sets the mark type (Area, Line, Bar…). The **Color**, **Size**, **Label**, **Detail** and **Tooltip** boxes take fields. Here `Bucket label` sits on **Color**, which splits the area into one band per holder.
5. **Data Source tab (bottom left).** Shows the raw table. Useful for checking that the data loaded.
6. **Undo** (Ctrl+Z / Cmd+Z) works for everything, so feel free to experiment.

## 4. What the fields in the Ratchet mean

Each row of `ratchet.csv` is one quarter × one holder of the debt × one debt type (mortgages or consumer credit), from 1951Q4 to 2026Q2.

| Field | Plain-language meaning |
|---|---|
| `Date` | The quarter, stored as its last day (e.g. 2026-06-30 = 2026Q2). |
| `Bucket label` / `risk_bucket` | **Who bears the credit risk**: Federal government (direct), GSEs & agency pools, State & local governments (the three *public* buckets, in cool colours), then Banks & credit unions, Private securitization & mortgage REITs, and Finance companies & other private (the *private* buckets, in warm colours). |
| `Is public` | True for the three public buckets. |
| `Sort order` | 1–6, the stacking order (federal at the bottom). |
| `Debt type` | `mortgage` (1-4 family home mortgages) or `consumer_credit` (cards, auto, student loans and so on). The chart adds both together, so leave it unfiltered ("All"). |
| `Share of total` | This bucket's slice of **all** household mortgages + consumer credit that quarter. Summed over debt types and buckets it is 100%. |
| `Public share` | The three public buckets combined. It went from **3.2% in 1952 to 56.4% in 2026Q2** ($10.77T of $19.10T), the headline finding. The same value repeats on every row of a quarter, so the sheet uses **Average**, not Sum. |
| `Nominal $M` / `Real $M` | The bucket's debt in millions of dollars, as reported and inflation-adjusted. |
| `Fed MBS share of scope` | The Fed's own holdings of agency mortgage-backed securities, as a share of the total (empty before 2009). This is part of the public share. |

How to read it against the findings (`analysis/findings.md`):

- The green **GSEs & agency pools** band swells through the **1980s (+18.8 pp)**. That is the slow structural build-out, not a crisis.
- The big step is **2007Q4 → 2011Q4: public share 36.1% → 49.2% (+13.1 pp)**, and it never reverses. Half of that is the warm private bands shrinking (private-label securitization lost 12.5 pp).
- In the **2001** recession the public share actually *fell* (−3.8 pp) as private securitization (amber) boomed.
- The navy **Federal government (direct)** band thickens after 2010. That's federal student loans.

## 5. If the file doesn't open or looks wrong

1. **Take a screenshot** of the whole Tableau window (including any error dialog) and send it to Claude. If there's an error, also copy the **exact error text**. Many Tableau dialogs have a "Show details"/"Copy" button, and the exact wording is what helps.
2. Things worth reporting even if there's no error:
   - Tableau asks you to **locate `ratchet.csv`**. Point it to `tableau/data/ratchet.csv` and carry on. Make sure you opened the `.twbx`, not the `.twb`.
   - The chart is **bars or a single blob** instead of stacked coloured bands.
   - **Colours** don't match the legend in `workbook_specs.md` §0.2 (cool blues/teal for public, warm red/amber/pink for private).
   - The **y axis isn't a percentage**, or the area doesn't reach 100%.
   - The **line is far above 100%** (it's summing instead of averaging).
   - The **legend or title is missing** from the dashboard.
3. Most of these can be fixed in place in a minute (see the matching step in §6). If the file won't open at all, use §6 to build it by hand.

## 6. Plan B: rebuild the Ratchet by hand (about 10 minutes)

This doesn't use the generated workbook at all.

1. Open Tableau Public. Under **Connect → To a File** choose **Text file** and pick `tableau/data/ratchet.csv`.
2. On the Data Source page, check the little type icons above each column. `date` should be a calendar (Date) and `share_of_total` / `public_share` should be `#` (number). Click an icon to change it if needed. Then click **Sheet 1** (bottom left).
3. Right-click the sheet tab → **Rename** → `Ratchet – main`.
4. **Right-click-drag** `date` from the Data pane onto **Columns**, release, and choose the **green** `QUARTER(date)` option (continuous, the one with an example like "Q2 2015").
5. Drag `share_of_total` onto **Rows**. It becomes `SUM(share_of_total)`.
6. In the **Marks** card dropdown choose **Area**.
7. Drag `bucket_label` onto **Color**. You now have stacked bands that fill to 100%.
8. **Percent axis:** right-click `share_of_total` in the Data pane → **Default Properties → Number Format… → Percentage**, 0 decimals.
9. **Order and colours:** click the `bucket_label` pill on Color → **Sort… → Sort by Field → `sort_order`, Minimum, Ascending**. Then click **Color → Edit Colors…**, select each bucket, and set the colour from `workbook_specs.md` §0.2 by double-clicking the bucket to open the colour picker and typing the hex code (Federal `#1C5CAB`, GSEs `#1BAF7A`, State & local `#3987E5`, Banks `#E34948`, Private securitization `#EDA100`, Finance cos. `#E87BA4`).
10. **Public share sheet:** click the new-worksheet icon at the bottom and rename it `Public share`. Put green `QUARTER(date)` on Columns as in step 4, then drag `public_share` to Rows. Right-click its pill → **Measure → Average**, and set Marks to **Line**.
11. **Dashboard:** click the new-dashboard icon (bottom bar) and rename the tab `Ratchet`. On the left, set **Size → Automatic** so the view fits whatever width the website gives it (the site's column is about 667 px wide; a fixed size would get clipped). Drag `Ratchet – main` onto the canvas, then drag `Public share` below it. Drag a **Text** object (bottom left, under *Objects*) to the very top and type `Who holds US household debt? 1952–2026`.

## 7. Save to Tableau Public

1. Optional tidy-up: right-click the **Ratchet** dashboard tab → **Hide All Sheets**. Only the dashboard then gets published as a view, which is what the website expects.
2. **File → Save to Tableau Public As…** and sign in if asked.
3. Name it exactly **`WhoHoldsTheDebt`** (no spaces). The name becomes part of the URL.
4. Tableau uploads it and opens the viz in your browser. Saving again later with the same name overwrites it, which is what you want for refreshes. Tableau Public saves to the web, not to your disk, so keep the `.twbx` in the repo as your local copy.
5. On the viz page, open the settings (gear or "⋯") and turn **Show Sheets as Tabs** off.

## 8. Connect it to the website

1. Your view URL is `https://public.tableau.com/views/WhoHoldsTheDebt/Ratchet`. Open it in a browser to check it loads. (The page you land on after saving looks like `…/app/profile/<profile-name>/viz/WhoHoldsTheDebt/Ratchet`. Both point to the same view.)
2. In Vercel: **Project → Settings → Environment Variables**, add:
   - `NEXT_PUBLIC_TABLEAU_PUBLIC_PROFILE` = your Tableau Public profile name (from step 1.1)
   - `NEXT_PUBLIC_TABLEAU_VIEWS` = `Ratchet` (a comma-separated list of the published sheet names; add the others as they get published)
3. **Redeploy**: Deployments → the latest deployment → **⋯ → Redeploy**. `NEXT_PUBLIC_*` variables are baked in at build time, so a redeploy is required.
4. Open https://household-debt-risk-web.vercel.app. Figure 1 should now be the live Tableau view. The `/methods` page shows which mode the site is using.

## 9. The quarterly refresh

The GitHub Action (`.github/workflows/refresh.yml`) re-runs the pipeline after each Fed Z.1 release (around the 20th of Mar/Jun/Sep/Dec) and saves the fresh CSVs.

1. On GitHub, go to the repo → **Actions** → the latest successful **refresh** run → scroll to **Artifacts** → download **`data-snapshots-<run id>`** (a zip).
2. Unzip it. Copy the files from its `tableau/data/` folder over the ones in this repo's `tableau/data/`.
3. Rebuild the packaged workbook: `python3 -I tableau/build_workbook.py` (from the repo root). This puts the new CSVs inside `WhoHoldsTheDebt.twbx`.
   *No Python handy?* Open the old `.twbx` instead, go to the **Data Source** tab, click the small arrow next to `ratchet.csv` on the left → **Edit Connection…**, and pick the new `tableau/data/ratchet.csv`.
4. Open `WhoHoldsTheDebt.twbx` in Tableau Public and check the last quarter. For 2026Q2 the public share should read **56.4%**; a new quarter will differ slightly.
5. **File → Save to Tableau Public As… → `WhoHoldsTheDebt`** and confirm the overwrite. The website picks up the change automatically; no redeploy needed.
6. Commit the updated CSVs and workbook files.

> If you edited the workbook by hand in Tableau, rebuilding with the script in step 3 replaces your edits. In that case use the *Edit Connection* route instead.

## Updating to v3 (recession bands, `Active crisis` parameter, three new dashboards)

v3 is still **one file**. Besides the Ratchet it now holds three more dashboards for figures 2–4: **`CrisisSmallMultiples`** (public share around each crisis, one panel per crisis), **`Collateral`** (debt mix by collateral, plus the home coverage ratio) and **`PaymentPriority`** (serious-delinquency transitions, one row per loan type). All four dashboards use **automatic sizing**, so they fit the site's column instead of being cut off at 1000 px. One open-and-save publishes all of them.

v3 also adds grey NBER recession bands behind the stacked areas. The band for the crisis the website is showing turns darker. It also adds the fields `Recession`, `Crisis id`, `Band` and `Is active crisis`, and the parameter `Active crisis`.

1. In the **Tableau Public app** choose **File → Open…** and pick the new `tableau/WhoHoldsTheDebt.twbx`. If it asks to upgrade the file, click **OK**.
2. **Re-apply the stack order** (the file still doesn't include it). Open the **Ratchet – main** tab. On the Marks card click the **Area** tab (`SUM(Share of total)`), then click the `Bucket label` pill on Color and choose **Sort… → Sort by: Field → `Sort order`, Aggregation: Minimum, Sort order: Descending**. The public holders should end up at the bottom, as in v2.
3. **Check the bands.** Light grey vertical bars should cover every NBER recession (1953–54, …, 2008–09, 2020) and sit **behind** the coloured areas. If they cover the areas instead, right-click the right-hand axis → **Move marks to back** on the Band pane (or swap the two pills on Rows). The axis on the left should read 0%–100%, with no second axis visible.
4. Optional: to test the highlight, right-click `Active crisis` in the Data pane (under Parameters) → **Show Parameter**, pick `gfc_2007`, and the 2008–09 band should darken. Then set it back to `none` and close the control. **The control doesn't need to be on the dashboard**, because the website sets the parameter itself.
5. Click through the three new dashboard tabs (`CrisisSmallMultiples`, `Collateral`, `PaymentPriority`) and check each one shows lines or areas, not an error or an empty sheet. The worksheets behind them are `Crisis SM – main`, `Collateral – share`, `Collateral – coverage` and `Payment priority – main`. Don't rename the dashboard tabs, because the website uses those exact names.
6. **File → Save to Tableau Public As…** with the same name **`WhoHoldsTheDebt`** and confirm the overwrite. This replaces the published version at the same URL. The Ratchet needs no Vercel change.
7. **Turn on the three new views on the website.** In Vercel go to **Project → Settings → Environment Variables** and edit `NEXT_PUBLIC_TABLEAU_VIEWS`, appending `CrisisSmallMultiples,Collateral,PaymentPriority`. The full value becomes:
   `Ratchet,CrisisSmallMultiples,Collateral,PaymentPriority`
   Then **Deployments → latest → ⋯ → Redeploy**. `NEXT_PUBLIC_*` variables are read at build time, so the redeploy is required. Check each one at `https://public.tableau.com/views/WhoHoldsTheDebt/<name>` first.

If the file doesn't open or the dual axis looks wrong, copy the exact error text (see §5) and use the hand-build below.

### Fallback: add the bands by hand (about 8 steps)

Start from your published v2 workbook, opened from Tableau Public, or a v3 file that opened without the bands. The data source needs the new `ratchet.csv` (**Data Source** tab → **Edit Connection…** → `tableau/data/ratchet.csv` if the `recession` and `crisis_id` columns are missing).

1. **Parameter:** Data pane ▸ the small arrow at the top → **Create Parameter…** Name it `Active crisis`, Data type **String**, Allowable values **List**. Add `none` plus every `crisis_id` from `tableau/data/crises.csv` (you can use **Add values from → Crisis id**, then add `none`). Set the current value to `none`.
2. **Calc `Band`:** **Analysis → Create Calculated Field…**, name `Band`, formula `IF [Recession] = 1 THEN 1 END`.
3. **Calc `Is active crisis`:** name `Is active crisis`, formula `[Crisis id] = [Active crisis]`.
4. On **Ratchet – main**, drag `Band` onto **Rows** to the **left** of `SUM(Share of total)`. Right-click it → **Measure → Average**.
5. Right-click the `SUM(Share of total)` pill → **Dual Axis**. Then right-click the right-hand axis → **Synchronize Axis** and untick **Show Header** to hide it.
6. On the Marks card, in the **AVG(Band)** tab, set the mark type to **Bar** and drag `Is active crisis` onto **Color**. Click **Color → Edit Colors…** and set False to `#D9D9D9` and True to `#9A9A9A`. Set Opacity to about 40%. If the bars are thin, click **Size** and drag it to the right until neighbouring quarters touch.
7. In the **SUM(Share of total)** tab check that the mark type is still **Area** with `Bucket label` on Color. Re-apply the Descending sort from step 2 above. Make sure the bars are behind the areas: `AVG(Band)` must be the **first** pill on Rows.
8. Right-click the left axis → **Edit Axis… → Fixed, 0 to 1**, title `Share of total`. On the dashboard, check that the colour legend still shows the six holders. Then save to Tableau Public as `WhoHoldsTheDebt`.

## 10. What's next

This is **v1**: one dashboard, kept deliberately simple so it's most likely to open cleanly. Later versions of the file will add, following `workbook_specs.md`:

- **The full Ratchet**: NBER crisis bands (reference bands driven by `crises.csv`) and policy-shock lines, the public-share and Fed MBS lines overlaid on the area as a synchronized **dual axis**, KPI tiles (public share now, change since 2007Q4) using **LOD calcs**, a "share vs $ trillions" switch, rich tooltips, direct labels, a source line, a phone **device layout**, and a hidden "Data" crosstab sheet for accessibility.
- **Richer versions of the other three dashboards** (v3 has simple first versions; see "Updating to v3" for publishing them): the parameters, reference lines and wrapped grids described in `workbook_specs.md`.
- Moving to **Tableau Desktop / Cloud** with a live database connection later is covered in `README.md` (*Upgrade later*).
