# Icon candidates (D7-1, for Eleonora to pick)

Eleonora decided on 2026-11-04 that the plugin is to be listed more widely, which needs a square 512–2048 px icon.
Two candidates, 1024 × 1024 PNG, drawn by `make_icons.py` with plain shapes. Neither has a brand mark or
Fed/Anthropic imagery, and neither is a copy of an existing logo. Neither is active: the validator looks for
`.claude-plugin/icon.png` or `assets/icon.png`, so the chosen file is copied there only after her pick.

| File | Idea |
|---|---|
| `candidate-a-ledger-bars.png` | Three bars on a baseline, the tallest split between two holders (navy background) |
| `candidate-b-dot-grid.png` | A 6 × 6 dot grid, partly filled, with one open dot, echoing Hot Potato's "who holds it" dots (light background) |

The validator notes that the listing icon may be taken only once, at the first submission, so pick before
anything is submitted. Nothing has been submitted to any listing.
